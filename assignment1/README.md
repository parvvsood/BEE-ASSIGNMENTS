## 📸 Overview

This repository contains the official personal portfolio website of **Parv Sood** — AI Engineer, Developer, and Creative Technologist. Designed with an editorial, Apple-inspired aesthetic, the website combines dark mode elegance, fluid glassmorphism, and responsive interactions into a seamless digital workspace.

---

## ✨ Features

- 🌐 **Cinematic Multilingual Welcome Screen**: An editorial 22-language preloader cycling through global greetings (*Welcome*, *Bienvenue*, *ようこそ*, *નમસ્તે*, *आपका स्वागत है।*, etc.) paired with a big, bold progress indicator in the bottom-right corner.
- 🌌 **Luxury Dark Aesthetic**: Pure black background (`#090909`) with a subtle ambient purple glow (`#8b5cf6`), glassmorphism floating navigation, and crisp typography.
- ⚡ **Zero-Dependency Core**: Lightweight architecture built entirely with pure Semantic HTML5, Vanilla CSS3, and ES6+ JavaScript—no external frameworks required.
- 🚀 **Hardware-Accelerated Performance**: Optimized layout math and CSS GPU acceleration (`transform: translateZ(0)`) running smooth 60/120 FPS animations.
- 🎯 **Interactive Portfolio Showcase**:
  - **About & Philosophy**: Narrative introducing core focus areas and engineering background.
  - **Skills Matrix**: Categorized tech stack cards with interactive subtle tilt and hover states.
  - **Featured Projects**: Filterable grid featuring live demos, GitHub repository links, and tech tags.
  - **Research & Publications**: Academic highlights and technical publications.
  - **Experience & Recognition**: Milestones, career trajectory, and accolades.
  - **Contact Section**: Functional, accessible contact form with custom notifications.
- 📱 **Adaptive & Responsive**: Mobile-first design system catering seamlessly to mobile phones, tablets, laptops, and 4K ultra-wide monitors.

## 🎨 Design Philosophy

> *"Simplicity is about subtracting the obvious and adding the meaningful."*

1. **Editorial Elegance**: High contrast dark mode coupled with refined letter-spacing and hierarchy.
2. **Micro-Interactions**: Hover states, smooth scrolling, and subtle accent glows offer tactile feedback without clutter.
3. **Typography First**: Script fallback chains guarantee clean rendering for Latin, Devanagari, Japanese, Korean, Arabic, and South Asian character sets.

## 🚀 Getting Started

### Local Development

No package manager or build step required! Simply clone and launch in any modern browser:

```bash
# 1. Clone the repository
git clone https://github.com/parvvsood/ParvPortfolioWebsite.git

# 2. Navigate to directory
cd ParvPortfolioWebsite

# 3. Open index.html in your default web browser
# (On macOS)
open index.html
# (On Windows PowerShell)
Invoke-Item index.html
```

Or serve locally with Python:

```bash
python3 -m http.server 8000
# Open http://localhost:8000 in your browser
```
